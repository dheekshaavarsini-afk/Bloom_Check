DATA STRUCTURE LAB

How BloomCheck works

A Bloom Filter uses a bit array and multiple hash functions to test set membership with low memory usage.

01

Start with zeros

The bit array is initialized with every bit set to 0.

02

Hash the element

Several hash positions are calculated for each element.

03

Set bits to one

Insertion sets all bits at the calculated positions to 1.

04

Check the positions

If any bit is 0, the item is definitely absent. If all are 1, it may be present.

InsertionO(k)k hash positions
Membership checkO(k)k bit checks
SpaceO(m)m bits in the filter
Implementation detail

This project uses a bytearray as the bit vector and SHA-256-based double hashing to generate repeatable positions. With a fixed number of hash functions, insertion and checking are O(1) with respect to the number of stored elements, assuming fixed-size inputs and constant-time hash computations.
